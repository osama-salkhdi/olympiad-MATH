# منصة الاختبارات التجريبية — الأولمبياد العلمي السوري (مكتب درعا)

منصة مستقلة لكل اختصاص (هذه النسخة: **الرياضيات**). كل منصة = مستودع GitHub خاص بها + Google Sheet خاص بها.

## محتويات المشروع
```
index.html          صفحة الطلاب
admin.html          لوحة التحكم (كلمة سر)
config.js           الإعدادات (رابط الخادم + اسم الاختصاص)
Code.gs             كود الخادم → يُلصق في Google Apps Script (لا يُرفع إلى GitHub)
assets/             style.css, common.js, app.js, admin.js, logo.png
samples/            index-sample.html (نموذج اختبار) + نموذج_الطلاب.xlsx (نموذج قائمة الطلاب)
```

## التشغيل لأول مرة (ملخص)
1. أنشئ Google Sheet جديداً ← الإضافات ← Apps Script ← الصق `Code.gs` ← ضع كلمة السر في `ADMIN_KEY`.
2. شغّل الدالة `authorize_` مرة واحدة (إذن Google Drive لحفظ صور الأسئلة).
3. Deploy ← New deployment ← Web app (Execute as: Me، Access: Anyone) وانسخ رابط `/exec`.
4. ضع الرابط في `config.js` داخل `SCRIPT_URL`.
5. أنشئ مستودعاً جديداً على GitHub (Public) وارفع كل الملفات ما عدا `Code.gs`، ثم Settings ← Pages ← main / root.

## الاستعمال اليومي (كله من لوحة التحكم)
- **الطلاب المسموحون:** أضف طالباً يدوياً، أو ارفع ملف إكسل (عمودان: رقم الاكتتاب + الاسم). التقييد مفعّل افتراضياً: لا يدخل إلا المسجّلون والمسموح لهم. الإضافة اليدوية لا يحذفها رفع الإكسل. يدخل الطالب برقم الاكتتاب فقط ويُعتمد اسمه المسجّل.
- **الاختبارات:** «استيراد ملف اختبار (HTML)» ← يظهر للطلاب مباشرة. سمِّ الملف `index2.html` ليصبح «الاختبار التجريبي الثاني».
- **النتائج والطلاب:** ملف كامل لكل طالب، ترتيب، إحصاءات الأسئلة، تصدير CSV.

## صيغة ملف الاختبار
مصفوفة `const QUESTIONS` (انظر `samples/index-sample.html`): `q` نص السؤال، `o` من 2 إلى 5 خيارات، `a` رقم الإجابة الصحيحة يبدأ من 0، `s` طريقة الحل، `fig` دالة الشكل (اختياري).
- المعادلات تُكتب بين `$ ... $` (داخل السطر) أو `$$ ... $$` (سطر مستقل)، وداخل القوالب `` ` ` `` تُكتب الشرطة المائلة **مضاعفة**: `$\\frac{a}{b}$`.
- لا تستعمل علامة `$` لغير المعادلات (مثل الأسعار).

## إنشاء منصة لاختصاص آخر
1. مستودع GitHub جديد + Google Sheet جديد + Apps Script جديد (الخطوات أعلاه).
2. انسخ الملفات نفسها، وغيّر في `config.js` فقط: `SCRIPT_URL` و`SUBJECT`.

## ملاحظات
- مفتاح الإجابات يصل إلى متصفح الطالب ليظهر له الصح والخطأ فوراً (مناسب للاختبارات التدريبية لا الرسمية).
- العلامات تُحسب في الخادم، ويُسمح بمحاولة واحدة لكل طالب في كل اختبار (لإعادة السماح احذف صفه من ورقة النتائج).
- تعديل اختبار بعد أن قدّمه طلاب لا يعيد حساب علاماتهم القديمة.
